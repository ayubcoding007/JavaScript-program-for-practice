ES Modules (ECMAScript Modules) are the standard module system built into JavaScript. They let you split 
code across files and explicitly share code using export and import.

What is an ES Module?

An ES module is simply a JavaScript file that
. can export code
. can import code from other files


Named Exports

// math.js
export const PI = 3.14;

export function add(a, b) {
  return a + b;
}

export class Calculator {
  multiply(a, b) {
    return a * b;
  }
}

Import them

// app.js
import { PI, add, Calculator } from './math.js';

console.log(PI);
console.log(add(2, 3));

const calc = new Calculator();
console.log(calc.multiply(4, 5));


Export at Bottom

const name = "Sam";

function greet() {
  return "Hello";
}
export { name, greet };

Default Export | A file can have one default export.

// user.js
export default class User {
  constructor(name) {
    this.name = name;
  }
}

Import

import User from './user.js';

const u = new User("John");


Default + Named Together

export const age = 25;
export default "Hello";

Import:

import message, { age } from './data.js';


Import Syntax Variations | Import all named exports

import * as math from './math.js';
console.log(math.PI);
console.log(math.add(1, 2));


Rename imports

import { add as sum } from './math.js';
console.log(sum(2, 3));


Rename exports

export { add as sum };


Export object as default (multiple values inside one default)

const name = "John";
const age = 25;

function greet() {
  return "Hello";
}

export default {
  name,
  age,
  greet
};

Import:

import user from './file.js';
console.log(user.name);
console.log(user.age);
console.log(user.greet());
