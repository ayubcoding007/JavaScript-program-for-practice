JSON

JSON (JavaScript Object Notation) is a lightweight data-interchange format used to 
store and exchange data between computers in a structured, text-based way.
In simpler terms, JSON organizes information into key-value pairs and arrays, 
making it easy for both humans to read and machines to process.

Example

{
  "name": "Asha",
  "age": 28,
  "isStudent": false,
  "skills": ["Python", "Design", "Writing"]
}

Impotant

1. The outer structure is an array ([ ]) because it contains a list of multiple users.
2. Each user inside the array is an object ({ }) with properties like id, name, age, etc.

So the structure is

[
  { "id": 1, "name": "Sheikh" },
  { "id": 2, "name": "Ayub" }
]

Breakdown

. [ ... ] → Array (holds multiple items)
. { ... } → Object (holds key-value pairs)
