Constructor 

A constructor is a special method inside a class that is automatically called 
when an object is created. It is used to initialize object properties.

A constructor is a function that runs automatically when you create an object 
from a class and helps set initial values.

Syntax Example

class Student {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }
}

Creating Object

const s1 = new Student("Ayub", 20);

console.log(s1.name); // Ayub
console.log(s1.age);  // 20

Key Points...
. Constructor name is always constructor
. It runs automatically when object is created
. Used to set initial values
. Only one constructor per class
