AJAX stands for Asynchronous JavaScript and XML.
It’s a web development technique used to update parts of a webpage without 
reloading the entire page.

Normally, when you click something on a website, the whole page reloads.
With AJAX, the browser can send and receive data in the background and 
update just a small part of the page.

How it works | AJAX uses
. JavaScript → to send requests
. HTTP requests → to communicate with a server
. Data formats like JSON or XML → to exchange data

Example
. Like a post on social media 
. Search suggestions appear while typing 
. Load more comments without refreshing

Important note
. Ajax support only brouser.
. Despite the name, AJAX doesn’t always use XML anymore—JSON is 
more common today.

<!DOCTYPE html>
<html>
<head>
  <title>AJAX Example</title>
</head>
<body>

<h2>AJAX Demo</h2>
<button onclick="loadData()">Get Data</button>
<p id="result"></p>

<script>
function loadData() {
  const xhr = new XMLHttpRequest();

  xhr.onreadystatechange = function() {
    if (xhr.readyState == 4 && xhr.status == 200) {
      document.getElementById("result").innerHTML = xhr.responseText;
    }
  };

  xhr.open("GET", "data.txt", true);
  xhr.send();
}
</script>

</body>
</html>
